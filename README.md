# Ja Wiggler Team Card

Ja Wiggler Team Card adalah halaman kartu profil interaktif yang dilengkapi dengan fitur dark mode dan like counter. Halaman ini memiliki 3 kartu profil yang berisi informasi mengenai anggota repository. Proyek ini dibuat sebagai studi kasus dalam Workshop Git & GitHub (Git Ready 2.0).

//

Ja Wiggler Team Card is an interactive profile card page featuring dark mode and like counter. The page have 3 profile cards that contain information about the repository members. This project was made for a case study at Git & GitHub workshop (Git Ready 2.0).

## What We've Learned

Dalam proyek ini, kami telah mempelajari bagaimana kita bisa menggunakan Git dan GitHub untuk mengorganisasi proyek lebih mudah dan untuk membangun portofolio bagi masa depan. 

Secara tidak langsung, kami juga mengetahui apa saja fungsi-fungsi teknologi front-end (HTML, JavaScript, CSS) yang digunakan untuk membuat website. 

Selain itu, kami juga memperoleh soft skill berupa kemampuan bekerja sama, berkomunikasi, memecahkan masalah, mengembangkan strategi, serta berinteraksi dengan sesama anggota dalam menyelesaikan proyek ini.
